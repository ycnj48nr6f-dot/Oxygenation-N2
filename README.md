### Personal board history + reset
The game uses browser `localStorage`.

- Everyone can use the same GitHub Pages link.
- Each learner has separate history/progress on their own browser/device.
- **Reset My Board** clears only that browser's progress.

### Matching & Comparison Center
Includes:
- Chronic bronchitis vs emphysema
- Pneumonia vs pleural effusion vs atelectasis
- Transudate vs exudate
- Chest-tube expected findings vs air leak
- Asthma green/yellow/red zones
- Peak-flow meter vs incentive spirometer
- Cystic-fibrosis organ systems
- ABG pattern matching

### ABG + MAP Lab
Interactive random cases reinforce:
- pH 7.35–7.45
- PaCO2 35–45 mmHg
- HCO3 22–26 mEq/L
- PaO2 >80 / about 80–100 mmHg for course practice
- No compensation, matching the course homework
- What each ABG number means
- Intervention direction based on physiology
- MAP calculation: `(SBP + 2 × DBP) ÷ 3`
- How low MAP/perfusion can change treatment priority

The MAP section uses the common clinical rule of thumb that a MAP below about 65 mmHg is concerning for inadequate organ perfusion; the whole patient and trend still matter.
